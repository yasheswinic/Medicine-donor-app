# 💊 Medicine Donation & NGO Matching System

A simple and powerful Streamlit web application that connects medicine donors with nearby NGOs in real time.

---

## 🚀 Features

- 👤 Donor registration (name, email, phone, medicine details)
- 🏥 NGO registration (name, city, locality, accepted medicines)
- 📍 City-based NGO matching system
- 💊 Medicine type tracking (tablet / syrup expiry logic ready)
- 📊 Live donor & NGO dashboard
- 🎨 Clean modern UI using Streamlit

---

## 🛠 Tech Stack

- Python
- Streamlit
